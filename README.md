# Robô das Câmaras

Plataforma B2G para descoberta e extração de contatos institucionais públicos das Câmaras Municipais brasileiras.

Aplicação Next.js implantável na Vercel, com consulta de municípios via IBGE, descoberta de domínios e coleta com origem auditável. Respeite robots.txt, limites dos servidores e LGPD.
